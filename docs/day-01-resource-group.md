
# Day 1 - Azure Resource Group

## Objective
Create a resource group in Microsoft Azure
to organize resources for my cloud lab.

## Environment
- Cloud Provider: Microsoft Azure
- Subscription: Azure Free Trial
- Resource Group: rg-careerlab-dev
- Region: East US 2

## Implementation Steps
1. Signed in to the Azure Portal.
2. Navigated to Resource Groups.
3. Selected Create.
4. Selected my Azure subscription.
5. Entered the resource group name.
6. Selected East US 2 as the region.
7. Reviewed and created the resource group.

## Verification
Confirmed that the resource group
appeared in the Azure Portal.

## What I Learned
Azure Resource Groups are logical containers
used to organize and manage cloud resources.

Resources within a group can include
virtual machines, networking components,
and security configurations.

## Next Steps
Create a Virtual Network and subnet
inside the resource group.
